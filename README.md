# ML models for targeting NS3/4A of HCV

Проект по построению QSAR модели для предсказания активности химических соединений в отношении NS3/4A - неструктурного белка вируса Гепатита С. 

## Препроцессинг данных: 

Экспериментально подтвержденные биоактивные соединения для NS3/4A были получены из базы данных ChEMBL. Для этого были проведены следующие этапы:

1. Сбор данных химических соединений против белкa NS3/4A из ChEMBL. Получено 1106 записей.
2. Фильтрация данных: отобраны ингибиторы со значениями IC50 и SMILES. Далее проведено удаление дубликатов. После фильтрации получено 495 уникальных молекул
3. Значение IC50 (полумаксимальная ингибирующая концентрация) были переведены в pIC50 с использованием логарифмической функциии: pIC50 = -log10(IC50)
4. Химические структуры были преобразованы из формата SMILES в 3D-SDF с использованием openbabel версии 3.1.0. Далее полученный файл был использован для для извлечения химических дескрипторов и фингерпринтов. 
5. Для расчета молекулярных дескрипторов была использована программма PaDEL-Descriptor. Всего для каждой молекулы было рассчитано 17 968 характеристик. Эти молекулярные дескрипторы и фингерпринты отражают информацию о структуре молекулы, например, молекулярная масса, количество связей и т.д.
6. Поскольку 17 968 характеристик - это слишком большое количество признаков для 495 молекул, был произведен отбор наиболее важных признаков. Выбор признаков необходим для предотвращения переобучения. Поскольку количество молекул должно быть минимум в 5 раз больше количества дескрипторов, было отобрано 50 самых важных признаков. Отбор признаков производился с помощью метода SelectFromModel и различных моделей: Decision Tree, Random Forest, Gradient Boosting. Итого с помощью каждой из моделей отобраны 50 наиболее важных признаков.
7. Нормализация данных. Были рассчитаны Z-оценки для признаков, удалены молекулы, где хотя бы один признак имеет Z-оценку больше 3 (для удаления выбросов). Затем признаки были разделены на бинарные и числовые. Бинарные признаки — это фингерпринты, которые не нуждаются в шкалировании. Числовые признаки масштабируются с помощью StandardScaler. 

Таким образом, целевая переменная - значение pIC50 (регрессионная задача). Признаки - 50 самых важных молекулярных дескрипторов и фингерпринтов, которые были отшкалированы.

## Выбор методов машинного обучения

Изначально для построения моделей были выбраны 3 метода: SVR, kNN Regressor, MLP Regressor. Каждый из трех методов (SVR, kNN, MLP) был применен к каждому набору отобранных признаков (DT, RF, GB). Таким образом, получается 9 разных моделей.

Построен сводный график по сравнению коэффициентов детерминации (R²) на различных моделях. Поскольку в целом различные методы отбора признаков дают схожые метрики, было принято решение оставить только одну модель для отбора признаков - Random Forest и продолжить подбор различных моделей для обучения именно на этом наборе данных.

Поскольку данные хорошо кластеризовались с помощью k-means, изначально было выдвинуто предположение, что модель kNN Regressor хорошо справится с задачей предсказания pIC50, что подтверждается значением коэффициента детерминации.
Таким образом, модель k ближайших соседей была выбрана бейзлайном для решения данной задачи: **RMSE = 0.68099, R² = 0.8290.**

В целях улучшения метрик, полученных с помощью baseline, было принято решение использовать методы градиентного бустинга. Однако, модель CatBoost дала **R² = 0.7516, XGBoost: R²: 0.7689** на тестовых данных. Также стоит отметить, что модели были склонны к сильному переобучению.

Далее для улучшения значений коэффициента детерминации и предотвращения переобучения было принято решение оптимизировать зазор R² между train и test с помощью библиотеки optuna. 

Оптимизация гиперпараметров:
```python
# Штраф за переобучение
gap = r2_train - r2_val
penalty = 20  # Коэффициент штрафа
score = r2_val - penalty * gap  # Минимизируем эту функцию
```

С помощью данного подхода была улучшена метрика, полученная с помощью baseline: **Test R2 = 0.8358**

![XGBoost](Plots/XGBoost with optuna.png)
